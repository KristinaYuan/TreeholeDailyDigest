# PKU Treehole · Daily Digest

在北大树洞网页中查看每日热门内容，按关键词订阅感兴趣的新帖。

树洞日报是一个浏览器用户脚本，通过篡改猴运行，复用树洞已有的登录状态。安装后，直接在原站打开日报，无需单独注册、配置服务器或提供账号密码。

## 功能

- **每日热门**：按收藏、评论、引用数或发布时间排序，可选日期或过去 24 小时。
- **关键词订阅**：每个关键词单独查看，支持未读筛选和独立的已读标记。
- **短期缓存**：结果缓存 5 分钟，刷新同一标签页可直接恢复，切换排序和订阅无需重复抓取。
- **原站阅读**：每条结果保留洞号，方便回树洞搜索并查看完整内容。

## 安装

需要一个支持篡改猴（Tampermonkey）的浏览器，以及可正常访问北大树洞的校园账号。

1. 安装并启用 [篡改猴（Tampermonkey）](https://www.tampermonkey.net/)。
2. 点击 **[安装树洞日报](https://github.com/KristinaYuan/TreeholeDailyDigest/releases/latest/download/treehole-digest.user.js)**，在篡改猴弹出的页面中确认安装。
3. 打开 [北大树洞](https://treehole.pku.edu.cn/ch/web/pc/index)，在学校页面正常登录；已登录时刷新页面即可。
4. 点击右下角「树洞日报」，或使用自动弹出的日报窗口。

如果点击链接后只显示脚本源码，请在篡改猴「管理面板 → 实用工具 → 从 URL 安装」中粘贴以下地址，再点击安装：

```text
https://github.com/KristinaYuan/TreeholeDailyDigest/releases/latest/download/treehole-digest.user.js
```

日常使用不需要 Node.js，也不需要启动本地服务。

安装链接始终指向最新正式 Release。请在篡改猴中开启脚本更新检查与自动安装更新；发布新版本后，篡改猴会按设置的周期检查和更新，刷新树洞即可使用新版。订阅和已读记录会保留。也可再次打开安装链接手动更新。

如果安装的是未配置更新地址的旧版，请通过上面的链接更新安装一次，以启用后续更新检查。

## 使用

### 查看热门

选择日期，点击 **Generate**。默认查看北京时间今天发布的帖子，可通过右侧排序框切换收藏榜、评论榜、引用榜或最新帖子。

| 按钮 | 作用 |
| --- | --- |
| Generate | 生成简报；有有效缓存时直接复用 |
| Refresh | 跳过缓存，重新抓取所选时段 |
| Stop | 停止本次抓取 |

界面会显示更新时间。抓取完成前请保持页面打开，关闭网页后不会继续运行，也不会在后台定时生成日报。

### 订阅关键词

在「我的订阅」输入一个关键词，点击 **Add**。点击已有关键词即可单独查看对应的新帖，点击旁边的 `×` 取消订阅。最多可保存 30 个关键词。

关键词同时匹配帖子正文和站内标签，无需区分标签或关键词，也不要求带 `#`。

| 订阅词 | 匹配示例 | 不匹配示例 |
| --- | --- | --- |
| 实习 | 暑期实习、`#实习` | — |
| AI | `AI`、`#ai`、AI实习 | daily、OpenAI、AIGC |
| gy | `GY`、gy同学、`#gy` | energy |

英文匹配不区分大小写，避免命中其他英文单词中的字串；中文支持部分文字匹配。订阅不搜索评论或图片中的文字。

阅读后点击「标为已读」，再用「只看未读」筛选此关键词下新发布的帖子。每个关键词分别记录已读状态。

### 打开方式

日报窗口底部可以关闭「打开树洞时显示日报」。之后仍可通过右下角按钮打开。

## 数据范围与隐私

榜单按**发帖时间**筛选，收藏和评论数采用抓取时的累计值。结果仅涵盖本次实际读取的帖子，每个列表最多显示前 100 篇。抓取有页数上限，站点分页变化也可能造成遗漏。

引用数根据其他已读取帖子正文中连续 6 位及以上数字推算，同一来源帖子只计一次，不要求带 `#`。它不包含评论中的引用，也不代表全站引用总数，可能误计或漏计。长帖可能被列表接口截断，完整正文和评论请回原站阅读。

所有帖子请求直接发送至树洞原站，不上传到第三方服务。脚本使用现有网页登录态，不收集校园账号密码，也不额外保存登录凭据。订阅、已读记录和打开偏好保存在当前浏览器；帖子仅作短期会话缓存，不会同步到其他设备。

本项目为非官方个人浏览工具，依赖树洞现有接口。若提示登录失效，请在原站重新登录；若提示限流或接口异常，请稍后重试。使用时请遵守站点规则，尊重校内内容的访问范围。

## 体验演示与本地开发

下载仓库后，用浏览器打开 [demo/index.html](demo/index.html) 即可体验界面。演示使用虚构帖子，不连接真实树洞账号。

修改源码后，需要 Node.js 20 或更新版本重新构建；无需安装额外 npm 依赖。

```sh
npm run build   # 生成用户脚本和单文件演示
npm test        # 运行测试
npm start       # 启动本地演示服务
```

本地服务地址为 <http://127.0.0.1:8765>。可安装的脚本位于 `dist/treehole-digest.user.js`。
